# I CAN FLY

高い崖から助走してジャンプし、地面の着地ゾーンにピタリと着地するシンプルなブラウザゲームです。
単一の HTML ファイルで動作し、PC とスマホの両方で遊べます。

## 遊び方

1. スペースキー(またはタップ)で走り出します。
2. 連打して加速します。放置すると減速します。
3. 崖の端が近づいたら、押しっぱなしにして角度ゲージを溜め、離した瞬間にジャンプします。
   押している時間が長いほど高角度になります。
4. 空中は操作できません。風に流されながら放物線を描いて落下します。
5. 着地ゾーンに入れば成功です。中心に近いほど高得点になります。ゾーンの外に落ちると死亡します。

## ルール

- 風の向きと強さは、スタート前にランダムで決まります。RUN 中・ジャンプ中は変化しません。
  振れ幅は序盤は小さく、ステージが進むほど大きくなります(上限あり)。
- 着地ゾーンの距離はステージごとにランダムで、幅はステージが進むほど狭くなります。
- 崖の端から遠い位置で踏み切ると、飛距離が減ります。端を越えても踏み切れずに落ちた場合は失敗です。
- 成功すると次のステージに進みます。失敗するとゲームオーバーです。
- ゲームオーバー後は「お手本を見る」か「リトライ」を選べます。お手本では、同じ風・同じゾーンで着地できる速度と角度のジャンプを青いゴーストが実演します。
- ハイスコアはブラウザの localStorage に保存されます。

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| 開始・加速 | スペースキー連打 | タップ連打 |
| ジャンプ(角度決定) | スペースキー長押し→離す | 長押し→離す |
| ゲームオーバー後の選択 | ←→ で選択、スペースキーで決定(クリックも可) | ボタンをタップ |

## 起動方法

ビルドは不要です。`index.html` をブラウザで開くだけで遊べます。

```
git clone https://github.com/<your-name>/<repo-name>.git
cd <repo-name>
open index.html   # Windows は start index.html
```

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で公開するブランチを選びます。

## パラメータ調整

ゲームバランスは `index.html` 冒頭の `CFG` 定数で調整できます。

| 区分 | 主なパラメータ |
| --- | --- |
| 助走 | 連打 1 回あたりの加速量、自然減速率、最大速度 |
| ジャンプ | 初速の係数、最小・最大角度、押下時間と角度の対応 |
| 踏み切り | 崖の端からの距離によるペナルティ |
| 風 | 初期の振れ幅、ステージごとの増加量、上限、空中での加速度への係数 |
| 物理 | 重力、キャラ身長、崖の高さ(身長 × 10) |
| 難易度 | 着地ゾーンの初期幅、ステージごとの縮小率、距離の変動範囲 |
| デモ | お手本の助走加速度、優先する角度 |

## 技術メモ

- HTML / CSS / JavaScript のみで、外部ライブラリや画像素材は使っていません。
- 描画は Canvas で、物理演算は固定タイムステップで行っています。
- スマホでは `touch-action: none` でスクロールとズームを抑止しています。
